#Portfolio Website

##Overview

This repo contains the files and items used in the portfolio for Sam Higgins.
A hosted version exists at <https://samhi113.com>

##Site Replication

This site and it's repo is made available under a [CC BY-NC license](https://creativecommons.org/licenses/by-nc/4.0/ "View License Definition"). In basic (but not fully extensible) language: you can use my work for non-commercial purposes, as long as you attribute me in your work.
As for replicating the site, please follow the following steps:

1. Visit the project's terminal, or open a terminal window and locate the folder for this project.
2. Install the packages by typing `npm i`
3. Run a live server for the project by typing `npm run serve`

and it should work!
